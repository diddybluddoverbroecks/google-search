# Google Search Messaging App

A Next.js application styled to resemble Google Search.
- The server stores the active trigger keyword (default: `message`).
- Changing the trigger via `/changepassword <new_word>` immediately disables old trigger words across all clients.
- Searching an old or incorrect keyword renders a 404 page.
- Group Chat title is styled as **9 Yellow 9 Blue 9 Green**.
- Alt-tabbing instantly reverts to the Google search page.
